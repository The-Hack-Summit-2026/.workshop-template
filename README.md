# Secret Protection Workshop

A 60-minute, hands-on workshop on GitHub Secret Protection, including secret scanning, validity checks, push protection, custom patterns, alert dismissal, and history cleanup.

Choose the guide for your role:

- [Participant Guide](PARTICIPANT-GUIDE.md): setup, lab exercises, checkpoints, and participant cleanup.

## Safety

Use a disposable repository. Never use real personal, customer, or production credentials. Provider-scanning exercises require only instructor-approved, revoked/nonfunctional test credentials; other examples are synthetic or inert. Revoke/rotate exposed credentials first: deleting files, dismissing alerts, or rewriting history does not revoke them or erase other copies.
